# RideMesh

Android mesh voice communication MVP for motorcycle riding groups.

This repository contains the V0.2 prototype source. The first proof-of-concept is phone-only push-to-talk over a multi-hop nearby mesh (A → B → C). Bluetooth helmet intercoms are an optional audio input/output layer for later road testing.
